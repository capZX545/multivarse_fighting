# Multivarse Fighting

بازی دو حالته با پایتون (Pygame):
- **Versus** — مبارزه رو در رو (سبک Mortal Kombat / Street Fighter)
- **Dungeon** — روگ‌لایک از بالا (سبک Soul Knight)

۶۴۰ کاراکتر انیمه، AI تطبیق‌پذیر، فروشگاه، ارتقا، لباس‌ها.
پلتفرم‌ها: دسکتاپ (Windows / Linux) و اندروید (APK).

> وضعیت: در حال ساخت — فعلاً فقط دیتابیس کاراکترها آماده است.
